# 빅데이터 학습실 — 데이터 과학 학습지 웹앱

『데이터 과학』 학습지 2쪽을 브라우저에서 하는 앱입니다. 탭 두 개로 나뉩니다.

| 탭 | 무엇 | 저장 |
|---|---|---|
| ① **빅데이터의 개념과 특징** | 정형·비정형 데이터와 3V 를 직접 만져 보며 익힌다. 괄호 채우기·분류 게임·단위 저울·실시간 카운터·확인 문제 (모두 자동 채점) | 브라우저 안에만 (점수는 탭② 제출 때 함께 전달) |
| ② **검색어 트렌드 분석하기** | 구글 트렌드 / 네이버 데이터랩으로 분석한 결과를 4단계로 채워 제출한다. **시각화 캡처 그림을 올릴 수 있다** | 선생님의 **구글 스프레드시트** (그림은 드라이브 폴더) |

- 대상: 고등학교 1학년 『데이터 과학』
- 학습목표: 빅데이터의 개념과 특징을 설명할 수 있다.
- 학생은 **구글 로그인이 필요 없습니다.** 학번 + 비밀번호로 들어갑니다.

---

## 학생에게 알려 줄 것 (3줄)

1. 알려 준 주소를 열고, **탭①** 에서 문제를 풀며 [정답 확인] 을 눌러 점수를 확인한다.
2. **탭②** 에서 학번·비밀번호로 들어가, 구글 트렌드(또는 네이버 데이터랩) 화면을 캡처해 올리고 1~4단계를 채운다.
3. 다 채우면 [제출하기]. 고칠 것이 있으면 다시 들어와 고치고 또 제출하면 된다(마지막 것이 남는다).

> 캡처 요령 — 윈도우는 **⊞ Win + Shift + S** 로 화면을 오린 뒤, 앱의 그림 상자를 누르고 **Ctrl + V**.
> 파일을 끌어다 놓아도 되고, 상자를 눌러 파일을 골라도 됩니다.

## 설치 (선생님, 15분)

### 1. 스프레드시트를 만든다

구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 붙입니다. (예: `빅데이터 학습지 - 1학년`)
이 시트가 곧 **답안이 쌓이는 곳**입니다.

### 2. Apps Script 편집기에 파일 6개를 넣는다

시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다. 왼쪽 **파일** 목록에서 `＋` 를 눌러
아래 이름으로 만들고, `src/` 폴더의 같은 이름 파일 내용을 **그대로 붙여넣습니다.**

| 편집기에서 만들 파일 | 종류 | 붙여넣을 내용 |
|---|---|---|
| `Code.gs` (이미 있음) | 스크립트 | `src/Code.gs` |
| `index` | HTML | `src/index.html` |
| `css` | HTML | `src/css.html` |
| `concept` | HTML | `src/concept.html` |
| `activity` | HTML | `src/activity.html` |
| `js` | HTML | `src/js.html` |

> ⚠️ HTML 파일은 이름에 `.html` 을 **적지 않습니다.** 편집기가 알아서 붙입니다.
> `index` 라고 만들면 `index.html` 이 됩니다. 이름이 하나라도 다르면 흰 화면이 뜹니다.

매니페스트도 맞춰 두면 좋습니다 — 편집기 **⚙️ 프로젝트 설정 → 「appsscript.json」 매니페스트 파일 표시**
를 켜고, `src/appsscript.json` 내용을 붙여넣습니다. (시간대와 웹앱 접근 방식이 정해집니다)
권한 범위는 **일부러 적지 않았습니다** — Apps Script 가 코드를 보고 필요한 것만 알아서 요청합니다.

### 3. 웹 앱으로 배포한다

오른쪽 위 **배포 → 새 배포 → 유형 「웹 앱」**

| 항목 | 값 |
|---|---|
| 실행 사용자 | **나** (선생님 계정) |
| 액세스 권한 | **모든 사용자** |

「배포」를 누르면 권한 승인 창이 뜹니다. 스프레드시트·드라이브 권한을 허용해 주세요.
(구글 확인을 받지 않은 앱이라는 경고가 나오면 **고급 → 이동**)

나온 **웹 앱 URL** 이 학생에게 알려 줄 주소입니다. QR 로 만들어 칠판에 띄우면 편합니다.

### 4. 시트를 준비한다

시트로 돌아와 새로고침하면 위쪽에 **📊 빅데이터 학습지** 메뉴가 생깁니다.
**[시트 만들기 / 머리글 정리]** 를 한 번 누르면 시트 세 장이 만들어집니다.

| 시트 | 무엇 |
|---|---|
| `제출 현황` | **채점용.** 학생 1명 = 1줄. 제출 시각·학번·이름·반·답안 전체·이미지 주소·개념 점수·총 글자 수 |
| `작성 중(임시 저장)` | 아직 제출하지 않고 쓰는 중인 내용 (누가 어디까지 썼는지 볼 수 있다) |
| `제출 기록(백업)` | 제출할 때마다 한 줄씩 쌓인다. 학생이 다시 제출해 덮어써도 예전 것이 남는다 |
| `계정(비밀번호)` | 학번·이름·뭉갠 비밀번호. **숨김 시트** |

시각화 캡처 그림은 스프레드시트 옆에 만들어지는
**`(시트 이름) - 제출 이미지`** 폴더에 쌓이고, 시트에는 주소만 적힙니다.

### 5. 배포한 뒤에 코드를 고쳤다면

**배포 → 배포 관리 → (연필 아이콘) → 버전 「새 버전」 → 배포** 로 올립니다.
「새 배포」를 만들면 **주소가 바뀌어** 학생이 예전 주소로 못 들어옵니다.

## 수업 중에 쓰는 교사 메뉴

시트 위쪽 **📊 빅데이터 학습지**

| 메뉴 | 하는 일 |
|---|---|
| 시트 만들기 / 머리글 정리 | 처음 한 번. 시트가 지워졌을 때 다시 눌러도 된다 |
| 제출 받기 ▶ 켜기 / ■ 끄기(마감) | 끄면 학생 화면에 안내가 뜨고 제출 단추가 막힌다 (임시 저장은 계속 된다) |
| 제출 현황 요약 | 제출 인원·수정 제출·이미지 올린 수·평균 글자 수·**탭① 개념 평균 정답률**·도구 분포 |
| 아직 제출 안 한 학생 보기 | 쓰는 중이지만 제출하지 않은 학생과 글자 수 |
| 🖼 **고른 줄의 이미지 보기** | `제출 현황` 에서 학생 줄을 누르고 이 메뉴를 고르면 **올린 캡처가 창으로 바로 뜬다** (드라이브를 열지 않아도 된다) |
| 🔑 학생 비밀번호 초기화 | 학번을 넣으면 비밀번호만 지운다. **쓴 내용은 그대로 남는다** |
| 📂 이미지 폴더 주소 보기 | 그림이 쌓이는 폴더 |
| 학생용 주소 보기 | 배포한 웹 앱 주소 |

## 자주 묻는 것

**학생이 비밀번호를 잊었어요** → 🔑 메뉴로 초기화하면, 그 학생은 다음 접속에서 이름을 확인하고
새 비밀번호를 정합니다. 쓰던 답안은 그대로입니다.

**같은 학생이 두 번 제출하면?** → `제출 현황` 의 같은 줄을 덮어쓰고 「제출 횟수」가 늘어납니다.
예전 내용은 `제출 기록(백업)` 에 남습니다.

**집에서 이어서 쓸 수 있나요?** → 됩니다. 답안이 시트에 저장되므로 학번·비밀번호로 들어오면
쓰던 곳부터 이어집니다. (2.5초마다 자동 저장)

**그림이 안 올라가요** → 그림 파일(PNG·JPG·WEBP·GIF)만 됩니다. 앱이 가로 1400픽셀로 줄여 올리므로
용량은 거의 문제가 되지 않습니다. 한 사람 **3장**까지입니다.

**컴퓨터실 공용 PC 인데 다음 학생에게 내 답이 보이지 않을까요?** → 오른쪽 위 **[나가기]** 를 누르면
그 컴퓨터의 로그인 정보가 지워집니다. 창을 닫아도 지워집니다(sessionStorage).
단, 탭①의 풀이 기록은 그 브라우저에 남으므로, 필요하면 탭① 아래 [↺ 전부 다시 풀기] 를 누르게 하세요.

**흰 화면만 나와요** → 편집기 파일 이름이 `index`·`css`·`concept`·`activity`·`js` 인지 확인하세요.
하나라도 다르면 `include` 가 실패해 아무것도 그려지지 않습니다.

## 개발자용

의존성이 하나도 없습니다(`npm install` 할 것이 없습니다).

| 명령 | 하는 일 |
|---|---|
| `npm test` | 서버 로직 **235가지** 검증 (가짜 시트·드라이브 위에서 진짜 `Code.gs` 를 돌린다) |
| `npm run check` | 문법 · 항목 이름 · 화면 아이디 · 서버 함수 · CSS 클래스 · 저작권 표시 대조 |
| `npm run preview` | `dist/preview.html` — **배포하지 않고** 브라우저로 확인 |
| `npm run build` | 위 세 가지를 순서대로 |

미리보기 로그인: `10101`(비번 `pw1234`, 쓰던 내용 있음) · `10102`(선생님이 초기화한 상태) · `10103`(처음).
브라우저 콘솔에서 `sheetDump('제출 현황')` 을 치면 시트에 무엇이 들어갔는지 표로 볼 수 있습니다.
